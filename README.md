# Java-object-oriented
Through a series of advanced academic assignments, I developed a strong foundation in object-oriented programming using Java. I designed and implemented modular systems involving class hierarchies, abstract classes, and interfaces. I gained hands-on experience with inheritance, method overriding, polymorphism, and encapsulation. The projects included building custom classes for rational numbers and geometric shapes (both 2D and 3D), implementing utility methods, and working with Java's Date class. I also applied advanced concepts such as cloning, dynamic arrays, variadic methods, and interface-based design to create reusable and maintainable code. These assignments sharpened my problem-solving skills and deepened my understanding of core Java principles and software design patterns.
